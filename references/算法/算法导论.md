# 算法导论（Introduction to Algorithms）

- 书目：Cormen/Leiserson/Rivest/Stein, *Introduction to Algorithms*, 4th ed.（CLRS）。
- 来源：`[本地]` 未联网确证；引用前先浏览器学习。

## 选型速查

| 需求 | 首选 | 复杂度 |
|---|---|---|
| 通用排序 | 归并/快排/Timsort | O(n log n) |
| 查找（有序） | 二分 | O(log n) |
| 集合去重/判存 | 哈希表 | 均摊 O(1) |
| 优先任务 | 二叉堆 | O(log n) 出入 |
| 图遍历/最短路 | BFS/DFS、Dijkstra、Bellman-Ford | 视规模 |
| 重叠子问题 | 动态规划/记忆化 | 状态数×转移 |
| 不相交集合 | 并查集（路径压缩） | 近似 O(α(n)) |

## 工程要点

1. **先量后优**：用数据规模与热点分析选结构，不凭直觉。
2. **空间换时间**有上限：缓存不命中与内存压力可能反噬。
3. **均摊分析**：动态数组扩容、并查集的代价要按序列看。
4. **正确性优先**：边界（空、单元素、重复、极值）先证明再实现。
5. **递归转迭代**：深度不可控时改显式栈，避免爆栈。
