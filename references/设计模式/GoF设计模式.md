# GoF 设计模式

- 书目：Gamma/Johnson/Vlissides/Helm, *Design Patterns: Elements of Reusable OO Software*, 1994。
- 来源：`[本地]` 未联网确证；引用前先浏览器学习。

## 三大类

| 类别 | 目的 | 代表模式 |
|---|---|---|
| 创建型 | 对象创建解耦 | 工厂方法、抽象工厂、建造者、原型、单例 |
| 结构型 | 类/对象组合 | 适配器、桥接、组合、装饰、外观、享元、代理 |
| 行为型 | 职责与协作 | 责任链、命令、迭代器、中介者、备忘录、观察者、状态、策略、模板、访问者 |

## 使用原则

1. 模式是**权衡后的复用方案**，不是目标；先考虑最简实现。
2. 优先组合而非继承；面向接口编程。
3. 找出程序中「变化的部分」并把它封装（变与不变分离）。
4. 过度模式化＝抽象税：无第二个用例时不预先抽象（YAGNI）。
