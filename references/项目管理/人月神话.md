# 人月神话（The Mythical Man-Month）

- 书目：Frederick P. Brooks Jr., *The Mythical Man-Month*, anniversary ed., 1995。
- 来源：`[本地]` 未联网确证；引用前先浏览器学习。

## 核心要点

1. **布鲁克斯法则**：向已延误的软件项目增加人力只会使其更延误——
   新人上手耗时 + 沟通路径随人数平方增长。
2. **概念完整性**：系统结构应由单一心智模型主导，设计一致性优先于功能数量。
3. **沟通成本**：n 人团队沟通链路 n(n−1)/2；用小团队、清晰接口压缩。
4. **进度幻觉**：「90% 完成」的剩余 10% 会再占一半时间；须按里程碑验证。
5. **文档与自描述**：程序自文档化优于外部说明；设计决策要留痕。
6. **试算原型**：先建一次性原型验证需求，再决定重构或抛弃。
7. **没有银弹**：软件复杂性是本质属性，工具只解决偶然复杂性。
